Software

  • open-archeOcsean: a curated catalogue of open resources useful to the archaeology of the Pacific and Southeast Asia regions. Access to the code and to the web application.

  • archeoViz Portal: an interactive catalogue of applications of the archeoViz software to archaeological datasets. Access to the application and to its compagnion blog.

  • archeoViz: an interactive (packaged R Shiny) application for the visualisation, exploration, and web communication of archaeological spatial. Access to the code, and to the application.

  • archeofrag.gui: an interactive (packaged R Shiny) application to access and explore archaeological refitting datasets with the archeofrag methods. Link to access to the code and to the application.

  • archeofrag: an R package implementing methods to assess the consistency of archaeological spatial units using the refitting relationships between fragments. Link to access to the code.

  • spatialCatalogueViewer:A 'Shiny' Tool to create interactive catalogues for geospatial data. Access to the code, and to the application.

  • Virtual Poeymaü: online visualisation of the archaeological remains collected during the excavation of the Poeymaü cave (Pyrenees) by Georges Laplace during the 1950s. It was developped in the context of the PAVO project (“Early Prehistory of the Ossau Valley”).

  • MAP Syntax Diagram: a R Shiny application to analyse divine onomastic sequences from the Old World. It was developped in the framework of the “Mapping Ancient Polytheims” project. Access to the code and to the application, link to the documentation.
